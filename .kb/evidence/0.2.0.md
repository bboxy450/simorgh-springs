Decisions, 2026-10-24:

- Match complete semicolon-separated `bath:type` values with whitespace
  trimming, using the same recognized values in normalization and Overpass.
  Substrings such as `nonthermal` do not denote a thermal bath.
- Natural OSM hot springs retain `hot` ahead of commercial classification;
  Wikidata onsen/thermal bath membership takes precedence over its hot flag.
- Website retains the complete parsed HTTPS URL, without credentials. It is
  never truncated into a different or broken URL. Other text follows existing
  scalar normalization, with an 80-scalar limit for hours.
- Only `fee=yes` uses a nonempty charge; absent/blank charge falls back to fee.
  Other fee values and missing fees are not inferred from charge.
- `SELECT DISTINCT` removes duplicate bindings introduced by multiple matched
  membership classes. Stable item/coordinate/image ordering and paging remain.
- Merge compatibility lives in `Kind::compatible`; the merge algorithm and
  missing-field fill list need no changes. Hours and website stay primary,
  including when absent, as access and fee already do.
