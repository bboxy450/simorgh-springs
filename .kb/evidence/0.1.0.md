# simorgh-springs 0.1.0 implementation evidence

Scope: standalone library and CLI, four open spring sources, normalization,
merge, offline fixtures, Apache-2.0 code license, signed public release as
bboxy450. No database or consumer application changes.

Implementation choices, 2026-10-23:

- Source streams yield `Result<Record>`; errors and early cancellation do not
  prove a complete pass. Progress counters are observations, not completion.
- Overpass uses a 20-degree global grid, four-way split on timeout/resource
  errors/response caps, depth ten maximum. Terminal errors stay visible.
- NOAA's live archive is XLSX, parsed with calamine. Fixture trims sheet rows
  without editing retained source values. Missing numeric temperatures are null.
- Missing source timestamps stay null instead of being invented.
- Coordinate O/Ø hemispheres mean east (Ost/Øst), documented in the public API.
- Matching is against primary coordinates. Exact Wikidata links override kind
  and distance, with the unconditional tap-never-merges rule preserved.
- Spatial indexing uses 150 m Earth-centered cubic cells, followed by exact
  great-circle distance. This handles the antimeridian and polar coordinates.
- CLI output is replaced atomically after all selected sources succeed.

Mechanisms:

- `src/types.rs` — typed records, merged provenance, source stream and progress.
- `src/client.rs` — shared request spacing, User-Agent, retries, timeout, caps,
  temporary file downloads; redirects cannot bypass the spacing gate.
- `src/sources/` — Overpass split/fallback, WDQS paging/subclass classification,
  GNIS ZIP/pipe rows, NOAA archival workbook.
- `src/normalize.rs` — tags, Unicode scalar limits, coordinates, Wikimedia URLs.
- `src/merge.rs` — stable precedence, deduplication, 150 m matching, linked Q-id
  shortcut, missing-field fill and primary-first source references.
- `src/main.rs`, `src/verification.rs` — sync JSONL and embedded offline checks.
- `fixtures/README.md` — capture date, exact request URLs/queries and hashes.
- `tests/core.rs`, `tests/sources.rs` — pure/CLI cases and loopback HTTP cases.

Verification and release command output is kept locally under `.local/logs/`,
with exact argv, UTC timestamp, exit status and log path in
`.local/commands.jsonl`. Logs and downloaded full datasets are excluded from
Git and the published package. No credentials or private-repository material
are part of this repository.

Verified before release:

- `cargo fmt --check` — exit 0.
- `cargo clippy --locked --all-targets -- -D warnings` — exit 0.
- `cargo test --locked` — exit 0; 18 core/CLI tests + 15 loopback tests.
- `cargo doc --no-deps` — exit 0.
- `cargo run --locked -- verify` — exit 0; Overpass 200, Wikidata 4,995 parsed
  bindings, GNIS 300 and NOAA 300; coordinates, photo hosts, precedence pass.

Initial verification found and fixed a Commons URL double slash and a clippy
collapsible-if finding. The corrected suite passed; initial logs are retained.

Rust 1.88.0 was installed under ignored `.local/rustup`. Rustup returned exit 1
because its subsequent self-update failed, but the toolchain installation
completed and direct toolchain binaries successfully compiled and ran the suite.
The command/log records distinguish installation from verification.

The OSM Wikidata link is internal merge metadata and is not serialized into
exported rows; the JSON provenance test checks the contributing Q-id remains
in `sources`.
